# Luke 47AI — Starter Project v0.2

**Intelligence Without Limits**  
A mobile-friendly starter for the Luke 47AI software suite.

## Included mini-applications
- Text & Notes
- Word Studio
- PowerPoint Studio
- Assignment Planner
- Presentation Builder
- CSV Table
- Calculator
- Quick Tools

## Run it
Open `index.html` in a modern browser. For the installable/offline PWA features, publish it using GitHub Pages or another HTTPS static host.

## Upload to your GitHub repository from Android
1. Download and extract `Luke47AI_Starter_v0.2.zip` on your phone.
2. Open your GitHub repository `Luke47AI`.
3. Tap **Add file** (or the `+` menu) and choose **Upload files**.
4. Select the files *inside* the extracted `Luke47AI_Starter` folder: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `luke47ai-logo.png`, and `README.md`.
5. Scroll down and tap **Commit changes**.

If GitHub's mobile page does not show Upload files, open the browser menu and enable **Desktop site**, then use **Add file → Upload files**.

## Publish as a website
After the files are committed:
1. Open the repository's **Settings**.
2. Find **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then **Save**.
5. Wait for GitHub Pages to provide the website link.

## Important
This is an early starter foundation, not the finished Luke 47AI product. Some document and PowerPoint exports load libraries from the internet, and advanced PDF editing, AI features, Android packaging, and the Windows desktop app still need to be developed. Do not upload passwords, API keys, or private data to this public repository.
